# AMineer Homebrew tap

Homebrew packages for [RasterNest](https://rasternest.app), the open-source screen capture and markup tool.

```sh
# macOS: the app plus the rnest command-line tool
brew install --cask amineer/tap/rasternest

# CLI only (macOS or Linux)
brew install amineer/tap/rnest
```

The cask and formula are updated automatically by the [RasterNest release workflow](https://github.com/AMineer/rasternest_app/actions/workflows/release.yml). Please report problems in the [main repository](https://github.com/AMineer/rasternest_app/issues).
